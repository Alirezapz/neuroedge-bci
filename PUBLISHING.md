# Publication scope

This source and aggregate-results edition excludes model/scaler/ONNX binaries,
individual-trial prediction records, scientific figures and recorded EEG replays.
Automated approval review blocked publishing the larger model/data collection
under general GitHub permission. It has not been published through another
encoding, tree or archive. The complete owner-delivered project bundle retains
all exact artifacts and actual predictions.

The repository is private and the authenticated account is its owner with admin
permission. Only source code and cohort-aggregate result tables belong to this
commit. Full model/data publication requires explicit approval for that payload
to Alirezapz/new-1. No blocked binary object is referenced by this edition.
